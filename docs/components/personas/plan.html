Personas — design & implementation plan

Agent Fleet · 2026-08-04 · Workspace-scoped agent roles (no LLM calls in this slice)

PR slice No model backend yet

Personas are the configuration surface for how agents behave: name, role prompt, default worker profile, model preference, tools, budget. This slice ships schema + API + Agents UI + seed starters. Wiring a real LLM/ACP driver is a follow-up; fleet-worker still runs shell/artifact work and does not call a model.

1. Goals

  • CRUD personas per workspace (cookie auth, membership required).
  • Seed 8 starter personas from product vision (+ blank/custom).
  • Replace empty Agents page with a usable catalog + create/edit form.
  • Store fields the orchestrator/driver will need later (worker_profile, role_prompt, model_preference).
  • Document how to run the full stack (docker-compose + development.md).

2. Non-goals (this slice)

  • Calling any LLM provider.
  • Auto-assigning personas to board tasks / WorkPlans (later).
  • Org-level shared persona catalog (workspace only).
  • Budget enforcement or tool sandbox policy engines.

3. Data model

personas
  id                 UUID PK (app-generated UUIDv7)
  workspace_id       UUID FK → workspaces
  slug               TEXT  unique per workspace
  name               TEXT
  description        TEXT default ''
  icon               TEXT default 'bot'   -- ui key: code, sales, ops, …
  role_prompt        TEXT default ''     -- system / persona instructions
  worker_profile     TEXT default 'coding'  -- maps to orch plan task field
  model_preference   TEXT nullable       -- e.g. auto | grok | claude | local
  temperature        DOUBLE PRECISION nullable
  max_budget_usd     NUMERIC(12,4) nullable
  tools              JSONB default '[]'  -- string tags for now
  is_starter         BOOLEAN default false
  is_default         BOOLEAN default false
  status             TEXT  active|archived
  created_by         UUID nullable FK → users
  created_at / updated_at / version

UNIQUE (workspace_id, slug). Partial unique optional later for one default per workspace.

6. UI (Agents page)

  • Header: “Agents & personas” + Seed starters + New persona.
  • Card grid: icon, name, description, worker profile chip, model preference.
  • Click card → side panel / inline form for edit (role prompt, tools, budget).
  • Default badge when is_default.
  • Toasts on create/update/seed (existing toast system).
