Key takeaways (outline)
  • Why production SQLite: eliminate network RTT; NVMe + single-tenant edge makes in-process DB competitive.
  • WAL first: concurrent readers/writers; manage checkpoints so WAL does not grow unbounded under always-on readers.
  • Single writer: set busy_timeout; use BEGIN IMMEDIATE for any write transaction to avoid DEFERRED deadlocks.
  • Hot path I/O: enlarge cache_size, enable mmap_size, synchronous=NORMAL with WAL.
  • Durability in cloud: custom VFS / Litestream / LiteFS when local disk is ephemeral.
  • Fit: read-heavy, sub-TB, latency-sensitive apps — not multi-region multi-writer or multi-TB OLTP.
